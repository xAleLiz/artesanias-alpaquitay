# Cómo administrar el catálogo de Artesanías Alpaquitay

La tienda usa GitHub Pages y el catálogo está guardado en **`productos.js`**.

## ¿Cómo se actualizan los productos?

1. Entra a tu cuenta de GitHub.
2. Abre el repositorio `xaleliz/artesanias-alpaquitay`.
3. Abre el archivo `productos.js`.
4. Pulsa el lápiz para editarlo.
5. Cambia los datos del producto siguiendo el mismo formato de los productos que ya aparecen.
6. Guarda los cambios con **Commit changes**.
7. Para que los clientes vean la actualización, los cambios deben llegar a la rama principal **main**. Si trabajas en una rama de prueba, primero hay que integrar esos cambios a main.

## ¿Qué se puede cambiar?

Cada producto tiene información como categoría, precio, imágenes y descripción en español e inglés. Las imágenes deben existir dentro de la carpeta `img/` y sus rutas deben escribirse igual que en los productos actuales.

**Importante:** GitHub Pages no tiene una base de datos ni un panel privado con contraseña dentro de la tienda. Por eso, esta versión no muestra un botón de administración a los clientes. La protección consiste en mantener privado el acceso de escritura al repositorio: solo las personas autorizadas en GitHub pueden publicar cambios.

Si prefieres, puedes enviarme aquí los productos nuevos o los cambios que quieras hacer y te ayudaré a actualizar `productos.js` en GitHub. No compartas tu contraseña de GitHub.
