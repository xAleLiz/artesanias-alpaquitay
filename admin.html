Guardar los cambios en GitHub

1. Ajusta las cantidades y pulsa Copiar archivo actualizado.

2. Abre Editar productos.js en GitHub e inicia sesión con tu cuenta de propietaria.

3. Selecciona todo el contenido del archivo, reemplázalo con el texto copiado y pulsa Commit changes. GitHub verificará que tengas permisos antes de guardar.

El inventario publicado se actualizará cuando GitHub Pages termine de desplegar los cambios. Esta primera versión no descuenta ventas automáticamente.
